AHC Digital Solutions — Video Tonlu Alternatif V2

Bu sürümde:
- Hero videosu Developer Coding Background_1080p.mp4 ile değiştirildi.
- Site paleti videodaki siyah / lacivert / soğuk mavi / beyaz tonlarına çekildi.
- Altın tema kaldırıldı.
- Navbar logosu görsel dosya yerine sade metin marka işaretine çevrildi; yamalı JPEG/PNG görünümü kaldırıldı.
- Hizmet alanları yarı şeffaf cam kutular olarak yeniden tasarlandı.
- Hizmet kartlarına kutu biçimli aksiyon butonları eklendi.
- Projeler yalnızca AHC Location ve AHC Auth olarak bırakıldı.
- Day House, AHC Driver ve diğer proje kartları kaldırıldı.
- Proje kartlarında ileride gönderilecek video önizlemeleri için geniş alan ayrıldı.
- Proje detay metinleri geldiğinde kartlar proje sunum sayfalarına bağlanacak şekilde geliştirilebilir.
- Masaüstü ve mobil düzenler korunmuştur.

Yerel test:
  npm install
  npm run dev

Production build:
  npm run build

Canlıya gönderme:
  git add .
  git commit -m "Add video-tone premium alternative"
  git push

Not: Bu paketin TypeScript kontrolü başarıyla tamamlandı. Bu çalışma ortamında Next.js Linux SWC paketi internetsiz ortam nedeniyle indirilemediğinden burada production build koşturulamadı; Windows projenizde npm run build ile son kontrolü yapın.
